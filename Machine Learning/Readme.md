## Machine Learning

**Topic:** Supervised vs. unsupervised learning

**What I learned:**
- Machine learning means a computer learns patterns from data instead of following fixed rules.
- **Supervised learning** uses data that already has the answers (labels). The model learns to predict the answer for new data.
- **Unsupervised learning** uses data with no answers. The model finds groups or patterns on its own.
- Supervised has two main types:
  - **Classification:** predicts a category (spam or not spam).
  - **Regression:** predicts a number (house price).

**Examples:**
- Predict if an email is spam → supervised (classification)
- Predict house price from size and location → supervised (regression)
- Group customers by shopping habits → unsupervised (clustering)

**Key point:**
If the data has a column with the answer you want to predict, it's supervised. If not, it's unsupervised.

**Mistake I made:**
I thought predicting a price was classification. It is regression, because the answer is a number, not a category.
